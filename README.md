# Projet-power-bi

Ceci est une visualisation d'une base de données. La base de données utilisée est une base anonymisée des utilisateurs de prime video.

l'objectif c'est montrer la différence entre deux visualisations entre 2 jeu de données l'un non modifié et un autre nettoyé, transformé et modélisé. 

les jeux de données seront mis à disposition dans un download.py
